# Extension cookbook

This index routes repository work. Extension anatomy and patterns are provisional until several
extensions have been developed.

| Task                                              | Read                                                                    |
| ------------------------------------------------- | ----------------------------------------------------------------------- |
| Extension entrypoint or type                      | `extension-entrypoint.md`, official Directus extension docs             |
| Shared runtime helper                             | `extension-utils.md`, `extension-utils-glossary.md`, `guards.md`        |
| Package/test infrastructure                       | `test-utils.md`, `../workspace.md`, `../testing.md`                     |
| Directus API, hook, endpoint, service, or sandbox | `official-directus-documentation.md`, Directus MCP                      |
| README or consumer skill                          | `documentation-and-skills.md`                                           |
| Naming or implementation pattern                  | `patterns-and-conventions.md`, then nearby code                         |
| Production or release audit                       | maintainer auditing skill, `../publishing.md`, packed artefact evidence |
