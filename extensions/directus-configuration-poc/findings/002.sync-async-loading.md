# Sync and async configuration loading

## Finding

Directus does not await the `defineHook` handler during extension bootstrap. An async extension
handler therefore cannot guarantee that setup has completed before Directus finishes booting.

All hook registration and setup required during bootstrap must be synchronous.

## Where async execution is valid

This does not prevent asynchronous work in registered event handlers. Individual Directus handlers
for filters, actions, initialization events, and schedules may be async, despite some Directus type
definitions declaring callbacks as void-returning.

Jiti recommends its async ESM-compatible import API:

```ts
import { createJiti } from 'jiti'
const jiti = createJiti(import.meta.url)
const config = await jiti.import('./path/to/file.ts', { default: true })
```

That pattern is appropriate inside an already-registered async event handler, but not during
extension setup when the loaded configuration determines which handlers must be registered.

## Consequence for the POC

The configuration file is normally required during setup because it contains orchestration data,
such as which events to listen to. The configuration must therefore be loaded synchronously.

Jiti still supports synchronous loading through its callable API, although Jiti marks that API as
deprecated.

```ts
import { createRequire } from 'node:module'

const require = createRequire(import.meta.url)
const { createJiti } = require('jiti')
const loadedModule = createJiti(import.meta.url)(configurationPath)
const config =
  typeof loadedModule === 'object' && loadedModule !== null && 'default' in loadedModule
    ? loadedModule.default
    : loadedModule
```

The POC implements both approaches:

- synchronous loading during extension setup;
- asynchronous loading inside a registered action handler.

Both approaches work in their respective lifecycle contexts. The synchronous API is required for
configuration that controls bootstrap-time registration; the async API remains suitable for
configuration loaded after registration.
