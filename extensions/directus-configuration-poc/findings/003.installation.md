# Finding 003: Installation

## Decision

Consumers must use a custom Directus image. Directus' npm installation flow requires a build stage
and copying the installed extension into `/directus/extensions` before starting Directus. See the
[Directus npm package installation guide](https://directus.com/docs/self-hosting/including-extensions#npm-packages).

The consumer must also:

1. install `@onderwijsin/directus-configuration-poc` in the build stage;
2. copy its package directory, including `package.json` and `dist/`, into
   `/directus/extensions/directus-configuration-poc`;
3. make the package available to the external config file through Node module resolution, for
   example at `/directus/configuration/node_modules/@onderwijsin/directus-configuration-poc`;
4. make the hook's runtime dependency `jiti` available from the installed extension; and
5. set `CONFIGURATION_PATH` to the container-visible TypeScript or ESM config file.

Example Dockerfile:

```dockerfile
# Build stage - install the npm package with Corepack available.
FROM node:24-alpine AS build

RUN corepack enable

WORKDIR /extension-build
RUN pnpm init
RUN pnpm add --save-exact @onderwijsin/directus-configuration-poc@0.1.0

# Final stage.
FROM directus/directus:12.2.0

USER root

# Directus discovers the hook from this directory.
COPY --from=build \
  /extension-build/node_modules/@onderwijsin/directus-configuration-poc \
  /directus/extensions/directus-configuration-poc

# The external config file must resolve the public package subpath.
COPY --from=build \
  /extension-build/node_modules/@onderwijsin/directus-configuration-poc \
  /directus/configuration/node_modules/@onderwijsin/directus-configuration-poc

# Jiti is required by the hook at runtime.
COPY --from=build /extension-build/node_modules/jiti /directus/node_modules/jiti

COPY configuration/config.ts /directus/configuration/config.ts

ENV CONFIGURATION_PATH=/directus/configuration/config.ts

USER node
```

Example environment:

```dotenv
CONFIGURATION_PATH=/directus/configuration/config.ts
```

Example config:

```ts
import { defineConfig } from '@onderwijsin/directus-configuration-poc/config'

export default defineConfig({
  value: process.env.MY_VALUE ?? '',
})
```

## Rationale

Installing the package only under `/directus/extensions` is enough for Directus to discover the
hook, but is not enough for a config file located at `/directus/configuration/config.ts` to resolve
the package's `./config` subpath. The package must be visible from the config file's module search
path as well.

The config runtime bundles Zod, but the hook intentionally keeps Jiti as a runtime dependency. The
consumer image must therefore preserve or separately install Jiti when copying the extension.

This is a trusted self-hosted setup. The config file is executable code in the Directus process and
is not suitable for untrusted input, Directus Cloud, or sandbox-only installation.
